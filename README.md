# Бот авторизации

Для локального запуска нужны JDK 25, работающий бэкенд Training Collector и собственный Telegram-бот от @BotFather. Скопируйте `.env.example` в `.env` и укажите:

- `AUTH_BOT_TOKEN` — токен этого Telegram-бота.
- `PLATFORM_URL` — адрес платформы, локально `http://127.0.0.1:8080`.
- `AUTH_SERVICE_KEY` — ключ, настроенный под этим же именем на платформе.

Запуск — `./gradlew run`, сборка — `./gradlew build`. Gradle читает локальный `.env` для запуска. Переменные процесса имеют приоритет. В продакшене передайте переменные контейнеру и используйте HTTPS или закрытую сеть для доступа к платформе.

```sh
docker build -t training-collector-auth-bot .
docker run --env-file .env -e BOT_MODE=POLLING training-collector-auth-bot
```

В контейнере задайте `PLATFORM_URL` с доступным из контейнера хостом. При таком локальном запуске бот работает в режиме long polling, достаточно одного запущенного экземпляра на Telegram-токен.

При регистрации тренер открывает персональную ссылку с сайта. Бот привязывает Telegram и сообщает об ожидании администратора. После одобрения бот присылает заголовок и код для первого входа отдельными сообщениями. Для последующих входов достаточно запроса с сайта.

Сквозной тест регистрации и выдачи кода находится в проекте `integration` бэкенда. Команда запуска приведена в его README.

## Vercel Hobby

Импортируйте репозиторий отдельным проектом. Dockerfile запускает HTTP-обработчик в режиме `WEBHOOK`. Локальный Gradle и IDEA используют `POLLING`. Для одновременной разработки используйте отдельного Telegram-бота.

В Production задайте:

- `PLATFORM_URL` — постоянный HTTPS-адрес Ktor.
- `AUTH_BOT_TOKEN` и `AUTH_SERVICE_KEY` — токен бота и его ключ доступа к Ktor.
- `BOT_USERNAME` — публичное имя этого бота без `@`.
- `TELEGRAM_WEBHOOK_SECRET` — отдельный секрет для этого бота. Его можно получить командой `openssl rand -hex 32`.

Сервис `delivery` получает события от Ktor на `POST /api/wake` и публикует их в Vercel Queues. Приватный обработчик вызывает JVM-сервис через привязку `AUTH_WORKER_URL`, которую создаёт Vercel. Событие очереди не содержит логин или код. При наличии отложенной отправки обработчик планирует следующий вызов на нужное время. При отсутствии работы очередь остаётся пустой.

После деплоя загрузите перечисленные переменные в локальное окружение, задайте `BOT_PUBLIC_URL` равным стабильному HTTPS-адресу этого проекта и из репозитория бэкенда выполните `python3 scripts/register-webhook.py auth`. Скрипт проверит имя бота и HTTP-обработчик, запишет имя на платформе и сверит зарегистрированный адрес через Telegram.
