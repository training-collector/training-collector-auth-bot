# Бот авторизации

Для локального запуска нужны JDK 25, работающий Training Collector Platform и собственный Telegram-бот от @BotFather. Скопируйте `.env.example` в `.env` и укажите:

- `AUTH_BOT_TOKEN` — токен этого Telegram-бота.
- `PLATFORM_URL` — адрес платформы, локально `http://127.0.0.1:8080`.
- `AUTH_SERVICE_KEY` — ключ, настроенный под этим же именем на платформе.

Запуск — `./gradlew run`, сборка — `./gradlew build`. Gradle читает локальный `.env` для запуска. Переменные процесса имеют приоритет. В продакшене передайте переменные контейнеру и используйте HTTPS или закрытую сеть для доступа к платформе.

```sh
docker build -t training-collector-auth-bot .
docker run --env-file .env training-collector-auth-bot
```

В контейнере задайте `PLATFORM_URL` с доступным из контейнера хостом. Бот работает в режиме long polling, достаточно одного запущенного экземпляра на Telegram-токен.

При регистрации тренер открывает персональную ссылку с сайта. Бот привязывает Telegram и присылает два сообщения — заголовок и код для входа.
